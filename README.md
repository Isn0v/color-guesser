# 🎨 Угадай цвет

Игра для тренировки цветовосприятия. Программа показывает цвет, ты запоминаешь его за несколько секунд, а затем воспроизводишь как можно точнее с помощью палитры HSL. Результаты сохраняются в `leaderboard.json`.

---

## 🚀 Быстрый старт

### Python (встроен на любом Mac / Linux)

```bash
python3 server.py
```

### Node.js (если установлен)

```bash
node server.js
```

После запуска открой в браузере: **http://localhost:3000**

> ⚠️ Просто открыть `index.html` двойным кликом тоже работает,
> но тогда лидерборд не сохраняется в файл (нет сервера).

---

## 🎮 Как играть

1. **Введи имя** в поле на стартовом экране
2. Нажми **▶ Начать игру**
3. **Запомни цвет** — у тебя есть несколько секунд (таймер показывает обратный отсчёт)
4. После того как цвет скроется, **выбери его в палитре**:
   - 🌈 **Левая полоса** — оттенок (Hue): тяни вверх/вниз по радуге
   - 🎨 **Средняя полоса** — насыщенность (Saturation): вверх = ярко, вниз = серо
   - ☀️ **Правая полоса** — яркость (Lightness): вверх = белый, вниз = чёрный
   - Большой квадрат справа — превью текущего выбранного цвета
5. Нажми **✔ Проверить** — увидишь результат раунда
6. Повтори для каждого раунда
7. После финального раунда — итоговый счёт сохраняется в лидерборд

---

## 📊 Оценка результата

| Счёт | Оценка |
|------|--------|
| 90–100 | 🏆 Отлично! |
| 70–89  | 👍 Хорошо! |
| 45–69  | 😐 Неплохо |
| 0–44   | 😬 Попробуй ещё |

**Счёт раунда** = `100 − (RGB-расстояние / 441) × 100`

**RGB-расстояние** — евклидово расстояние в пространстве RGB (0 = идеальное совпадение, 441 = максимум).

**ΔE (Delta-E)** — воспринимаемое глазом различие цветов с учётом неравномерной чувствительности зрения к разным оттенкам.

**Итоговый счёт** = сумма очков за все раунды (например, 3 раунда → max 300 очков).

## ⚙ Настройки

| Параметр | По умолчанию | Диапазон | Описание |
|----------|-------------|----------|----------|
| Время запоминания | 5 сек | 1–30 | Сколько секунд виден цвет |
| Количество раундов | 3 | 1–10 | Раундов за одну игру |

## 🏆 Лидерборд

- Хранится в файле **`leaderboard.json`** (до 200 записей, сортировка по итоговому счёту)
- Отображает: место (🥇🥈🥉), имя, счёт / максимум, количество раундов, дату
- Кнопка 🗑 **Очистить** удаляет все записи (с подтверждением)

### Формат записи в leaderboard.json

```json
{
  "name": "Иван",
  "totalScore": 255,
  "maxScore": 300,
  "rounds": 3,
  "roundScores": [85, 92, 78],
  "date": "08.09.2026"
}
```

## 🛠 Технологии

---

## 💡 Советы

- Обращай внимание на **все три** полосы — чаще всего ошибка идёт по яркости
- ΔE < 10 — глаз практически не видит разницы; ΔE > 30 — цвета заметно отличаются
- Тренируйся с коротким временем (2–3 сек) для максимального эффекта
